# موقع مكتب جاد العبدالله للمحاماة

موقع ويب ثنائي اللغة (عربي/إنجليزي) لمكتب جاد للمحاماة والاستشارات القانونية،
مُهيَّأ لمحركات البحث عبر توليد صفحات HTML ثابتة، مع لوحة تحكم محلية لإدارة المحتوى.

الموقع المنشور: <https://jaadlegal.com>

## التشغيل المحلي

```powershell
npm install
npm start
```

ثم افتح <http://127.0.0.1:3000/> للموقع، أو <http://127.0.0.1:3000/admin> للوحة التحكم.

> الخادم المحلي يخدم المسارات الحقيقية (`/about/`, `/en/practices/` ...) تمامًا كما تفعل الاستضافة،
> لذلك ما تراه محليًا هو ما سيُنشر.

## البناء

```powershell
npm run build
```

يقوم بأمرين:

1. `tools/build-icons.mjs` — يبني مجموعة أيقونات مصغّرة (‎~8KB‎) من مكتبة lucide بدل تحميل المكتبة كاملة (‎370KB‎).
2. `tools/build.mjs` — يولّد صفحة HTML كاملة المحتوى لكل مسار وبكل لغة، إضافة إلى `sitemap.xml` و `404.html`.

**مهم:** أي تعديل على `script.js` أو `index.template.html` أو `data/site-data.json` يتطلّب إعادة البناء.
النشر من لوحة التحكم يشغّل البناء تلقائيًا قبل الرفع، فلا حاجة لتشغيله يدويًا عند تعديل المحتوى.

### ضغط الصور

```powershell
npm install            # لتثبيت sharp (حزمة تطوير)
npm run build:images
```

يولّد نسخ WebP مضغوطة بجانب الصور الأصلية، إضافة إلى أيقونات الموقع وصورة المشاركة.
يُشغَّل عند إضافة صور جديدة فقط.

## بنية المشروع

### المصدر (يُحرَّر يدويًا)

- `index.template.html` — قالب الصفحة المشترك (ترويسة، تذييل، قوائم). العلامات `{{LANG}}` و `{{SEO_HEAD}}` و `{{APP}}` يملؤها البناء.
- `script.js` — المحتوى ثنائي اللغة، الموجّه (routing)، بيانات السيو، وبناء الصفحات.
- `styles.css` — التصميم والاستجابة للجوال والوصولية.
- `data/site-data.json` — المحتوى القابل للتحرير من لوحة التحكم.
- `tools/` — أدوات البناء.
- `server/` — لوحة التحكم المحلية (Express).

### المولَّد (لا يُحرَّر يدويًا — يُعاد إنشاؤه بالبناء)

- `index.html` والمجلدات `about/`, `practices/`, `practice/*/`, `cases/`, `case/*/`, `blog/`, `article/*/`, `consulting/`, `contact/`, `privacy/`, `terms/` ونظائرها تحت `en/`.
- `sitemap.xml`, `404.html`, `assets/vendor/icons.js`.

### الأصول

- `assets/logo.*`, `assets/founder.*` — الشعار وصورة قيادة المكتب.
- `assets/office/`, `assets/clients/`, `assets/trust/` — صور المكتب وشعارات العملاء والجهات.
- `assets/fonts/` — خط Thmanyah Serif للعناوين.
- `assets/legal-documents/` — ملفات الأحكام والرخصة كما وردت.

## الروابط والسيو

- الروابط حقيقية وقابلة للفهرسة: `/about/` وليس `#/about`. الروابط القديمة بصيغة الهاش تُحوَّل تلقائيًا.
- العربية على الجذر (`/`) والإنجليزية تحت `/en/`، ومربوطتان بوسوم `hreflang`.
- لكل صفحة عنوان ووصف ورابط أساسي (canonical) وبطاقات مشاركة وبيانات منظمة (JSON-LD) خاصة بها.
- `robots.txt` و `sitemap.xml` و `site.webmanifest` و `CNAME` موجودة في الجذر.

## النشر

الموقع يُنشر عبر GitHub Pages من الفرع `main`. زر "نشر" في لوحة التحكم يعيد البناء ثم يحفظ ويرفع التغييرات.
